Are.na Board

Paste the link of your Are.na channel. Every block becomes a tile you can move, rotate, flip (its Are.na description is on the back) and group. Anyone with the board's link can rearrange it with you, and new blocks you add on Are.na appear by themselves.

The channel must be open or closed (public), not private.

✳ Are.na Board
Saved in this browser only: set up Firebase to share the board (see board/README.md).

How to use

Drag a tile
move it (and every selected tile)
Double-click
flip it: its Are.na description is on the back
⟳ top handle
rotate (hold Shift to snap)
✥ bottom-left
tilt in 3D (or Alt/Option + drag)
◢ bottom-right
resize
Shift + click
add to the selection
Shift + drag
select an area
Drag the background
move around
Pinch / Ctrl + scroll
zoom
G
group the selected tiles into a cluster
Cluster title bar
drag it to move the whole cluster; double-click to rename
F · R · Delete
flip · straighten · remove from the board
Cmd/Ctrl + Z
undo your last change

Everyone with this board's link can change it, live. New blocks you add to the channel on Are.na appear here within half a minute.
